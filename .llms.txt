# MACE (Multi-Agent Consensus Engine)

MACE is a high-performance Meta-Agent orchestrator built in Rust, powered by Model-Consensus Driven Development (MCDD) and strict Compliance Governance.

## Core Philosophy
MACE does not generate code directly. It orchestrates underlying AI CLI tools (like Claude Code, Aider, Gemini CLI) by provisioning physical Git Worktree sandboxes, capturing their stdout, and using Tree-sitter AST to resolve semantic conflicts (Consensus) when multiple agents mutate the same repository simultaneously.

## Tech Stack
- **Language**: Rust
- **Async Runtime**: Tokio
- **TUI**: Ratatui & Crossterm
- **Isolation**: Git Worktree
- **Semantic Engine**: Tree-sitter
